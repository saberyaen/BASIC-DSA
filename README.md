# Basic-DSA

Python solutions for the 20 Basic DSA Problems (Units I–III) listed in the assignment.

## Structure
- `recursion/`: Questions 1–6
- `backtracking/`: Questions 7, 9, 10
- `searching/`: Questions 11–14
- `sorting/`: Question 15
- `stacks/`: Questions 16–19
- `linked_list/`: Question 20

## Run a solution
From the repository root, run a file with Python 3, for example:

```bash
python recursion/q01_print_1_to_n.py
```

Each file includes a small example or interactive input. Read the comments and practise explaining the algorithm and dry run before your assessment.

## Questions included
1. Print 1 to N using recursion
2. Factorial of N
3. Fibonacci number
4. Sum of digits
5. Power x^n
6. Check if array is sorted recursively
7. Print all subsequences of a string
8. Tower of Hanoi
9. Permutations of a string
10. Subset sum
11. First and last occurrence in a sorted array
12. Count occurrences in a sorted array
13. Floor and ceil in a sorted array
14. Search insert position
15. Merge two sorted arrays
16. Valid parentheses
17. Next greater element
18. Min stack with O(1) minimum lookup
19. Reverse stack using recursion
20. Remove duplicates from a sorted linked list
